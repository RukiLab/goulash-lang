# はじめに

`Goulash` は、モダンな文法と厳密なエラー検出を備えた v0.1 処理系です。

主な特徴は以下のとおりです。

* 同一ランタイムで CUI と GUI を切り替えられます。
* 通常は CUI で動作し、`-tags gui` で GUI 機能を有効にできます。
* ツリーウォーク型インタプリタで動作し、中間ファイルを生成しません。
* `if` や `while` などの条件式では、厳密に `bool` 型を要求します。
* 日本語テキストは rune 単位で扱い、日本語も 1 文字として数えます。
* 配列・map は参照セマンティクスを持ちます。
* `#include`、`#define`、条件付きプリプロセスに対応しています。
* GUIでは描画、入力、音声、ウィジェットなどの機能を利用できます。

# インストールとビルド方法

## 必要環境

Go 1.25 以上が必要です。

## CUIビルド

```sh
cd goulash
go build ./...
go test ./...
```

コマンド名 `gsh` のバイナリを作る場合は、出力名を指定します。

```sh
go build -o gsh .          # Linux / macOS
go build -o gsh.exe .      # Windows
gsh run examples/hello.gsh
```

## GUIビルド

GUI機能を使用する場合は、ビルドタグ `gui` を付けます。

```sh
go build -tags gui ./...
go test -tags gui ./...
go run -tags gui . run examples/gui_hello.gsh
```

> `TestGuiRender` など一部のGUIテストは Ebiten の制約により、1プロセスにつき1回だけウィンドウを生成します。2回目以降は自動的にスキップされます。

# コマンドの使い方

```text
gsh run <file.gsh> [--keep] [--gui] [--cui] [-- args...]   スクリプトを実行します
gsh repl                                            対話環境（REPL）を起動します
gsh lex <file.gsh>                                  字句トークン列を表示します
gsh parse <file.gsh>                                構文木（AST）を表示します
gsh help                                             ヘルプを表示します
```

## `gsh run`

```sh
gsh run examples/hello.gsh
```

スクリプトを実行します。

### `--keep`

将来のトランスパイラ向けに予約されているフラグです。

v0.1 では何も行いませんが、指定してもエラーにはなりません。

### `--gui` / `--cui`

コマンドラインからの強制指定で、コード内の `#mode` より優先されます。

```sh
gsh run examples/gui_hello.gsh --gui
gsh run examples/gui_hello.gsh --cui
```

`--gui` はウィンドウを開きます（GUIビルドでのみ有効）。
`--cui` は端末で実行します（GUI組込の呼出は未定義エラーになります）。

### コマンドライン引数

ファイル名の後に `--` を置くと、その後ろをスクリプトの引数として取得できます。

```sh
gsh run main.gsh -- hello world
```

スクリプト側では `args()` で取得します。

`-` から始まる引数は `--` の後に記述してください。GUIビルドで `--` より前に指定されたオプション形式の引数はエラーになります。

## `#mode`

実行モードをコード内で指定します（`gsh run` のみ有効。REPL は常に CUI です）。

```hsp
#mode cli
```

- `#mode cli`：端末で実行します（ウィンドウを開きません）
- `#mode gui`：ウィンドウを開いて実行します
- 省略時：`gui`（ウィンドウを開きます）
- 複数ある場合：有効な行の最後が勝ちます（`#ifdef` の無効分岐内は無視、`#include` 先も対象）
- `--gui` / `--cui` が指定された場合はそちらが優先されます

GUI モードには `-tags gui` ビルドが必要です。CUI ビルドで GUI モードの
スクリプトを実行すると、起動前にエラーになります。

## `gsh repl`

REPLを起動します（常に CUI。`#mode` は無視されます）。

```sh
gsh repl
```

以下のいずれかで終了します。

```text
exit
:quit
:q
```

括弧 `(`、角括弧 `[`、波括弧 `{` が閉じられていない場合は、継続プロンプト `>>` が表示されます。

## `gsh lex`

字句解析結果を確認します。

```sh
gsh lex examples/hello.gsh
```

## `gsh parse`

構文木（AST）を確認します。

```sh
gsh parse examples/hello.gsh
```

# 字句構造

## 文の区切り

`Goulash` では、文を**改行**で区切ります。

```hsp
x = 10
y = 20
mes(x + y)
```

セミコロン `;` は字句解析では `SEMICOLON` として認識されますが、v0.1 のパーサでは拒否されます。

```hsp
x = 10;   // エラー
```

文の区切りには改行を使用してください。

---

## コメント

### 行コメント

```hsp
// コメントです
mes("hello")
```

`//` から行末までがコメントです。

### ブロックコメント

```hsp
/*
  コメントです
*/
```

ブロックコメントは**ネスト可能**です。

```hsp
/*
  外側
  /*
    内側
  */
  外側
*/
```

---

## 識別子とキーワード

識別子は次の形式です。

```text
[A-Za-z_][A-Za-z0-9_]*
```

次のキーワードは識別子として使用できません。

```text
def if else repeat while switch case default
as break continue return try catch
true false null
```

`goto`・`gosub`・`elif` に特別な意味はなく、通常の識別子として使用できます。
`*` ラベル構文は存在しないため、`*` で始まる行は構文エラーになります。

---

## 空白

以下は基本的に無視されます。

* スペース
* タブ
* `\r`

改行 `\n` は文の区切りとして意味を持ちます。

# リテラルと基数表記

## 整数リテラル

整数は `int64` の範囲で扱います。

| 種類   | 表記          | 例           | 10進値 |
| ---- | ----------- | ----------- | ---: |
| 10進数 | なし          | `42`, `007` |   42 |
| 16進数 | `0x` / `0X` | `0xFF`      |  255 |
| 2進数  | `0b` / `0B` | `0b101`     |    5 |
| 8進数  | `0o` / `0O` | `0o17`      |   15 |

プレフィクスの大文字・小文字は区別されません。

```text
0xab == 0XAB
```

字句解析時に10進数へ変換されるため、パーサや実行系は元の基数を意識する必要がありません。

`gsh lex` や `gsh parse` でも10進数として表示されます。

---

## 整数の使用例

```hsp
mes(0xFF)          // 255
mes(0b101 & 0b011) // 1
mes(0o10 | 1)      // 9

x = 0x10
mes(x * 2)         // 32
```

---

## 不正な基数リテラル

| ソース                    | エラー                                    |
| ---------------------- | -------------------------------------- |
| `0x`                   | `malformed hexadecimal literal`        |
| `0b`                   | `malformed binary literal`             |
| `0b2`                  | `malformed binary literal`             |
| `0o8`                  | `malformed octal literal`              |
| `0xg`                  | `malformed hexadecimal literal`        |
| `0x1p3`                | `malformed hexadecimal literal`        |
| `0xFFFFFFFFFFFFFFFFFF` | `hexadecimal literal out of range`     |
| `0x1.5`                | `hexadecimal floats are not supported` |

アンダースコアによる桁区切りは v0.1 では使用できません。

```hsp
0xFF_FF   // 非対応
```

---

## 浮動小数リテラル

次の形式が利用できます。

```text
3.14
.5
2e3
1.2E-4
```

指数部には `+` または `-` を付けられます。

```text
2e+3
2e-3
```

基数プレフィクス付き浮動小数は非対応です。

## 文字列リテラル

文字列はダブルクォートで囲みます。

```hsp
"hello"
"こんにちは"
```

シングルクォートは使用できません。

利用できるエスケープは以下です。

```text
\"
\\
\n
\t
\r
\0
```

未知のエスケープ、文字列中の改行、閉じられていない文字列はエラーになります。

---

## 真偽値リテラル

```hsp
true
false
```

---

## 配列リテラル

```hsp
a = [1, 2, 3]
b = []
c = [[1, 2], [3, 4]]
```

配列はネストできます。

要素の型は混在可能です。

```hsp
a = [1, "hello", true, null]
```

末尾のカンマも利用できます。

```hsp
a = [1, 2, 3,]
```

---

## mapリテラル

```hsp
m = {"name": "Alice", "score": 98}
e = {}
```

キーは文字列に限ります。

```hsp
mes(m["name"])
m["level"] = 3
```

存在しないキーを読み取るとエラーになります。

読み取り前に `has()` で確認できます。

```hsp
if has(m, "level") {
    mes(m["level"])
}
```

存在しないキーへの書き込みは、そのキーを新しく作成します。

---

## mapのドット記法

mapはドット記法でもアクセスできます。

```hsp
m = {"name": "Alice", "score": 98}

mes(m.name)
m.level = 3
```

次の2つは同じ意味です。

```hsp
m.name
m["name"]
```

読み取り、書き込み、複合代入のいずれにも使用できます。

# 型と値

`Goulash` の値には次の8種類があります。

| 型          | 説明             | 例            |
| ---------- | -------------- | ------------ |
| `null`     | 未定義・空          | `null`       |
| `int`      | 64bit符号付き整数    | `42`         |
| `float`    | 64bit浮動小数      | `3.14`       |
| `string`   | 文字列            | `"hello"`    |
| `bool`     | 真偽値            | `true`       |
| `array`    | 可変長配列          | `[1, 2]`     |
| `map`      | 文字列キー・挿入順の連想配列 | `{"a": 1}`   |
| `function` | 関数値（クロージャ）     | `def f() {}` |

## intとfloat

比較・等価判定では `int` と `float` を自動的に比較できます。

```hsp
mes(10 == 10.0)  // true
```

配列とmapは同じ実体を共有します。


# 演算子と優先順位

## 演算子一覧

| 分類  | 演算子                                  | 説明                    |
| --- | ------------------------------------ | --------------------- |
| 算術  | `+ - * / %`                          | 加減乗除・剰余               |
| ビット | `& \| ^ ~ << >>`                     | AND・OR・XOR・NOT・左/右シフト |
| 比較  | `== != < <= > >=`                    | 等価・不等価・大小比較           |
| 論理  | `&& \|\| !`                          | 論理積・論理和・論理否定          |
| 代入  | `= += -= *= /= %= &= \|= ^= <<= >>=` | 代入・複合代入               |
| その他 | `. [...] (...)`                      | フィールド・配列・関数呼び出し       |

---

## 優先順位

数字が小さいほど優先順位が高くなります。

| 優先度 | 演算子               | 結合 |
| --: | ----------------- | -- |
|   1 | `()` `[]` `.`     | 左  |
|   2 | `-` `!` `~`       | 右  |
|   3 | `*` `/` `%`       | 左  |
|   4 | `+` `-`           | 左  |
|   5 | `<<` `>>`         | 左  |
|   6 | `<` `<=` `>` `>=` | 左  |
|   7 | `&`               | 左  |
|   8 | `^`               | 左  |
|   9 | `\|`              | 左  |
|  10 | `==` `!=`         | 左  |
|  11 | `&&`              | 左  |
|  12 | `\|\|`            | 左  |

ビット演算は等価比較より強く結合します。

```hsp
a & b == c
```

は、

```hsp
(a & b) == c
```

として解釈されます。

したがって、

```hsp
if flags & 0xF0 == 0x10 {
}
```

は意図どおりマスク判定として利用できます。

---

## ビット演算

ビット演算は整数にのみ使用できます。

```hsp
mes(6 & 3)      // 2
mes(6 | 3)      // 7
mes(6 ^ 3)      // 5
mes(~5)         // -6
mes(1 << 4)     // 16
mes(256 >> 3)   // 32
```

`float` や `string` に対して使用すると実行時エラーになります。

シフト数は `0`～`63` の範囲で指定してください。

```hsp
-8 >> 2   // -2
```

`>>` は算術右シフトです。

# 文

## 変数代入

```hsp
x = 42
name = "Alice"
arr[0] = 99

```

左辺には次を指定できます。

* 変数
* 配列要素
* map要素
* mapのフィールド

未定義の変数への代入は、その場で変数を作成します。

複合代入も利用できます。

```hsp
x += 1

x <<= 2
```

## 式文

式だけを独立した文として記述できます。

```hsp
mes("hello")
x + 1
```

値を使用しない場合でも文として有効です。

## if

```hsp
if x > 0 {
    mes("positive")
} else if x == 0 {
    mes("zero")
} else {
    mes("negative")
}
```

条件式は必ず `bool` 型である必要があります。

```hsp
if 1 {
}   // エラー
```

条件分岐の連鎖は `else if` と記述してください（`elif` という綴りは通常の識別子であり、キーワードではありません）。

```hsp
if x == 1 {
} else if x == 2 {
} else {
}
```

## repeat

### 回数指定

```hsp
repeat 5 {
    mes("hello")
}
```

### カウンタ付き

```hsp
repeat 3 as i {
    mes(i)
}
```

表示される値は、

```text
0
1
2
```

です。

### 配列指定

```hsp
repeat ["a", "b"] as x {
    mes(x)
}
```

### インデックス付き

```hsp
repeat ["a", "b"] as i, x {
    mes(str(i) + ":" + x)
}
```

結果：

```text
0:a
1:b
```

### 仕様

* 整数は `0` 以上である必要があります。
* 配列を指定すると要素を順番に反復します。
* `as x` の `x` は各要素のコピーです。
* `as i, x` の `i` は添字、`x` は要素です。
* カウンタ変数はループ内でのみ有効です。
* カウンタは読み取り専用です。
* 配列要素の変更は元の配列には書き戻されません。
* 配列を変更する場合は `a[i] = ...` を使用してください。
* 反復回数はループ開始時に確定します。
* ループ中の `push()` によって反復回数は増えません。
* 整数の `repeat` では `as i, x` は利用できません。
* ネストしたループで同じ変数名を使うと、内側の変数が一時的に外側を隠します。

---

## while

```hsp
i = 0

while i < 5 {
    mes(i)
    i = i + 1
}
```

条件が `true` の間、繰り返します。

```hsp
while true {
    // 無限ループ
}
```

ループを抜けるには `break` を使用します。

---

## switch

```hsp
switch x {
    case 1, 2 {
        mes("one or two")
    }

    case 3 {
        mes("three")
    }

    default {
        mes("other")
    }
}
```

仕様：

* 検査対象の式は1回だけ評価されます。
* `case` は複数の値をカンマで指定できます。
* `default` は最大1個です。
* `default` の位置は自由です。
* フォールスルーはありません。
* 最初に一致した `case` だけ実行されます。
* 比較には深い比較が使用されます。
* 配列やmapの比較にも対応します。
* `int` と `float` は自動的に比較可能です。

---

## break / continue

```hsp
repeat 10 as i {
    if i == 5 {
        break
    }

    if i == 2 {
        continue
    }

    mes(i)
}
```

### `break`

`repeat`、`while`、`switch` を終了します。

### `continue`

`repeat`、`while` の次の周回へ進みます。

`switch` 内で発生した `continue` は、外側のループへ伝播します。

ループ外の `break` / `continue` はエラーになります。

また、関数呼び出しをまたいで伝播することはありません。

---

## try / catch

```hsp
try {
    mes(1 / 0)
} catch(e) {
    mes("caught: " + e)
}
```

エラーが発生すると `catch` が実行されます。

`catch` の変数には、位置情報付きのエラーメッセージが文字列として格納されます。

```hsp
try {
    data = noteload("save.txt")
} catch(e) {
    data = ""
}
```

`catch` 変数は `catch` ブロック内だけで有効です。

`break`、`continue`、`return`、`end()` は捕捉されず、そのまま伝播します。

任意のエラーは `throw()` で発生させられます。

---

## return

```hsp
def max(a, b) {
    if a > b {
        return a
    }

    return b
}
```

`return` は関数内でのみ使用できます。

値を省略した場合は `null` を返します。

```hsp
return
```

---

## 関数定義

```hsp
def greet(name) {
    mes("Hello, " + name)
}

def add(a, b) {
    return a + b
}

greet("Alice")
mes(add(1, 2))
```

関数はクロージャとして定義時の環境を保持します。

パラメータの重複、および組み込み関数と同名の定義はエラーになります。

---

## デフォルト引数

```hsp
def greet(name, mark="!") {
    mes("Hello, " + name + mark)
}

greet("Alice")
greet("Bob", "?")
```

仕様：

* 末尾のパラメータにだけ既定値を指定できます。
* 既定値は呼び出し時に、呼び出し元の環境で評価されます。
* 既定値付きパラメータの後ろに必須パラメータは置けません。
* 省略された場合だけ既定値の式が評価されます。
* 既定値の式から他のパラメータを参照することはできません。

# 組み込み関数

## 組み込み関数の読み方

以下の表では、すべての関数について同じ形式で記述します。

| 項目      | 内容            |
| ------- | ------------- |
| 関数      | 関数名と引数        |
| 説明      | 関数そのものの意味     |
| GUIでの挙動 | GUIモードで何が起こるか |
| CUIでの挙動 | CUIモードで何が起こるか |

### 表中の表現

* **共通**：GUI / CUI で同じ意味です。
* **GUIのみ**：GUI専用機能です。
* **CUIのみ**：CUI側の機能です。
* **非対象**：その環境では意味を持ちません。
* **未定義**：v0.1では環境差が明文化されていない部分です。

# 10.1 出力・文字列化

### `strmid`

`start` が負数の場合は末尾から数えます。

### `instr`

```hsp
instr(s, sub)
instr(s, start, sub)
```

見つからない場合は `-1` を返します。

返される位置は絶対インデックスです。

### `strtrim`

`mode`：

|   値 | 動作   |
| --: | ---- |
| `0` | 左右両方 |
| `1` | 左のみ  |
| `2` | 右のみ  |

`chars` を省略すると空白が対象です。

### `asc()` / `chr()`

```hsp
asc("A")
```

は `65` を返します。GUI `input()` の制御文字（Backspace はコード `8`）にも使え、`asc(input()) == 8` で判定できます。空文字列はエラーです。

```hsp
chr(65)
```

は `"A"` を返します。サロゲート・範囲外はエラーです。

### `getpath`

モード値を加算して組み合わせます。

|    値 | 意味          |
| ---: | ----------- |
|  `0` | 複製          |
|  `1` | 拡張子を除去      |
|  `2` | 拡張子のみ       |
|  `8` | ディレクトリ部分を除去 |
| `16` | 小文字化        |
| `32` | ディレクトリのみ    |

# 10.3 数値・数学

| 関数                       | 説明                   | GUIでの挙動 | CUIでの挙動 |
| ------------------------ | -------------------- | ------- | ------- |
| `int(v)`                 | 整数へ変換します             | 同じです    | 同じです    |
| `float(v)`               | 浮動小数へ変換します           | 同じです    | 同じです    |
| `abs(v)`                 | 絶対値を返します             | 同じです    | 同じです    |
| `sqrt(v)`                | 平方根を返します             | 同じです    | 同じです    |
| `sin(v)`                 | 正弦を返します              | 同じです    | 同じです    |
| `cos(v)`                 | 余弦を返します              | 同じです    | 同じです    |
| `tan(v)`                 | 正接を返します              | 同じです    | 同じです    |
| `atan(y)` / `atan(y, x)` | 逆正接を返します             | 同じです    | 同じです    |
| `exp(v)`                 | `e^v` を返します          | 同じです    | 同じです    |
| `log(v)`                 | 自然対数を返します            | 同じです    | 同じです    |
| `pow(base, exp)`         | 累乗を返します              | 同じです    | 同じです    |
| `limit(v [, lo [, hi]])` | 値を指定範囲に収めます（省略した `lo` / `hi` は最小値 / 最大値） | 同じです | 同じです |
| `length(arr)`            | 配列の要素数を返します          | 同じです    | 同じです    |
| `rnd(n)`                 | `0` ～ `n-1` の乱数を返します | 同じです    | 同じです    |
| `randomize([seed])`      | 乱数系列を初期化します          | 同じです    | 同じです    |

補足：

* `int(float)` は0方向へ切り捨てます。
* `string` は数値として解析されます。
* `bool` は `true -> 1`、`false -> 0` です。
* `abs()` は元の `int` / `float` 型を維持します。
* `sqrt()` は負数でエラーになります。
* 三角関数の角度単位はラジアンです。
* `atan(y, x)` は2引数時に `atan2` として動作します。
* `log(0)` および負数はエラーです。
* `limit()` は引数がすべて `int` の場合、結果も `int` です（整数範囲で丸めます）。
* `limit(v)` はそのまま `v` を返します。`limit(v, lo)` は上限なし、`limit(v, lo, hi)` は両端で丸めます。
* `randomize()` に整数を指定すると再現可能な乱数系列になります。
* 引数なしでは現在時刻を使って初期化します。

# 10.6 プロセス・環境

| 関数                    | 説明                 | GUIでの挙動                  | CUIでの挙動                  |
| --------------------- | ------------------ | ------------------------ | ------------------------ |
| `exec(name, args...)` | 外部コマンドを非同期に起動します | 起動したら `0` を返してすぐ戻ります（終了は待ちません）。入出力は透過的に表示します | 同じです |
| `pipeexec(name, args...)` | 外部コマンドを実行し標準出力を返します | 終了まで待って標準出力を文字列で返します（標準入力は切り離し、標準エラーは透過）。起動失敗・非0終了はエラーです | 同じです |

`getenv()` は未設定時に `null` を返します。

`exec()` は起動成功で `0` を返してすぐ戻ります（非同期。終了コードは返しません）。出力の取り込み・終了待ちが要る場合は `pipeexec()`（終了コードが `0` 以外はエラー）を使います。

### `input()` の即時モード（GUI）

GUI の `input()` はブロックせず、前回呼出以降に入力された確定文字列を返します（IME確定分を含みます。変換中は `imeget()` で取得）。OS のロケール依存変換（配列・shift・caps 対応）で、新しい入力は即時、押し続けると 24 tick 後に再発火し、以降 4 tick ごとに発火します。何もなければ `""` です。毎フレーム呼び出すことを想定しています。

Backspace・Tab・Enter・Esc・Delete は制御文字（コード `8`・`9`・`13`・`27`・`127`、同じリピート付き）として返るため、`asc()` と組み合わせて行編集が組めます（`"\r"` との比較、または `asc(k) == 13` で確定判定）。矢印・ファンクションキー等の非文字キーは現れません（物理キーは `getkey()` を使います）。

```hsp
s = ""
while true {
    k = input()
    if k != "" {
        if k == "\r" {
            break
        }
        s = s + k
    }
    await()
}
```

リピート間隔（60fpsでの目安）：初回は即時、約400ms後に再発火、以降約67msごと。短い無入力区間（OS リピートの隙間程度）は同一セッションとして継続し、長い沈黙や異なる文字で新しいセッションになります。

注意：

* GUI の `input()` は引数を取りません（プロンプトは `mes()` で表示してください）
* `inputbox` フォーカス中は `""` です（ボックスがキー所有権を持ちます）
* IME 変換中は制御キーを返しません（変換の編集・確定が優先されます）
* CUI の `input([prompt])` は従来通り行単位のブロッキング入力です

`stick()` は廃止されました。方向・決定系は `getkey()`（矢印 `37`～`40`、決定 Space/`Z`/Enter、キャンセル Esc/`X`）、クリックは `clicked()` で取得してください。

## `enum`

連番の整数定数を定義します。

```hsp
enum Color { Red, Green, Blue }
mes(Color_Red)    // 0
mes(Color_Green)  // 1
mes(Color_Blue)   // 2

enum { A, B = 5, C }
mes(A)  // 0
mes(B)  // 5
mes(C)  // 6
```

* 名前付き `enum Name { ... }` は `Name_` 接頭辞付き（`Color_Red`）で定義されます。無名は素の名前です。
* 値は `0` から自動連番し、`=` で明示値（`-` 可）を指定するとそこから数え直します。複数行・末尾カンマ可です。
* `#define` 同様、宣言行以降の同一ファイル末尾までテキスト置換されます。`.` 直後のフィールド名（`m.Red`）は書き換えません。
* 重複定義はエラーです。非活性区間（`#ifdef` 不成立内）の行は字句解析に届かないため、本体ごと無視されます。
* `enum` 単体は通常の識別子としても使用できます（`enum = 5` は変数代入です）。
* 素の `enum` はパーサ段階で展開されるため、`#ifdef` からは参照できません（`#ifdef` が必要な定数は `#define` を使用してください）。

## `#define` の注意

`#define` はテキスト置換です。

そのため、

```hsp
#define MAX 100
```

とすると、`.` の直後のフィールド名を除き、同名の識別子が置換対象になります。

変数名・関数名との衝突に注意してください。

定数名には英大文字を使用することを推奨します。

REPLでは入力ごとにプリプロセス状態が初期化されます。

そのため、`#define` はその入力内でのみ有効です。

### 候補ウィンドウの位置について（調査結果）

候補ウィンドウの位置を直接指定する手段は、Ebiten の公開 API には存在しないため、
スクリプト側から調節することはできません。

ただし Ebiten 内部では、Windows（`ImmSetCandidateWindow`）・macOS・Web のいずれでも、
`input()` 行のカーソル位置を基準に候補ウィンドウが追従します。
Goulash は `ime(1)` 中の入力行カーソル位置を毎 tick 通知しているため、
候補ウィンドウは常に入力行の近くに表示されます。

直接制御が必要になった場合は、Ebiten 側に API が追加されるのを待つか、
`gsh/gui` パッケージで `textinput.Field.HandleInputWithBounds` に渡す矩形を
変える実装検討が必要です（現状は入力行カーソル位置に固定しています）。

# まとめ：GUIとCUIの使い分け

`Goulash` の標準実行モードはGUIです（`#mode` 省略時はウィンドウが開きます）。端末で実行するには `#mode cli` を指定します。

```text
CUI
├─ 標準入出力
├─ ファイル操作
├─ 文字列操作
├─ 数値計算
├─ 配列・map
├─ HTTP
├─ プロセス・環境変数
└─ スクリプト制御
```

GUIビルドでは、これに加えて、

```text
GUI
├─ ウィンドウ
├─ 2D描画
├─ キーボード
├─ マウス
├─ ゲームパッド
├─ タッチ
├─ IME
├─ 音声
└─ ウィジェット
```

を利用できます。

特にゲームやGUIアプリケーションでは、

```hsp
while true {
    // 入力
    if getkey(37) {
        x -= 1
    }

    // 更新
    x += 1

    // 描画
    cls()
    pset(x, y)

    // 次のフレームまで待つ
    await()
}
```

のように、`入力 → 更新 → 描画 → await()` の流れで記述できます。

# v0.1の基本方針

`Goulash` v0.1 では、曖昧さを減らすため、以下を特に重視しています。

* 条件式は `bool` に限定します。
* ビット演算は整数に限定します。
* エラーには可能な限りファイル名・行・列を付けます。
* 改行を文の区切りとして使用します。
* 配列・mapの動作を明確に定義します。
* GUIとCUIの違いを、実行環境ではなく組み込み関数単位でも確認できるようにしています。

サンプルプログラムについては `examples/`、仕様の回帰確認については各テストファイルを参照してください。

今後のバージョンアップでは、仕様変更があった組み込み関数について、GUI・CUIの両方の挙動を本表へ反映します。
